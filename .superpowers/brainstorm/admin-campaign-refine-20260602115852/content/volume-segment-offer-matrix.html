BISON-Style Campaign: Previous Volume -> Category -> Different Offer

This is not just conversion. It is a segmented offer matrix.

Mechanism Type: Volume Segment Offer Matrix

C

Category C - High BISON buyer

How this fits Admin

Campaign has one parent record. Under it, add a mechanism card called Volume Segment Offer Matrix. It generates or imports debtor categories, stores the offer per category, and lets Sales Dashboard show the exact offer for each debtor.
