🔐 One-time Setup Walkthrough

Step-by-step to get the bot running.

  1. Create the bot: Telegram → @BotFather → /newbot → copy the token
  2. Add bot to group: "Wwwwwwwwww High School 2.0" → Add Members → your new bot → Admin permissions (so it can read messages in topics)
  3. Important: In BotFather → /setprivacy → Disable. This lets the bot see all group messages (otherwise it only sees commands and mentions).
  4. Create MD topic: a private topic in the group for your digest. Only you should see this.
  5. Get topic IDs: run the bot with just the token set → in each topic send /chatid → bot echoes the thread_id
  6. Fill .env: use the Topics tab above to generate the file content
  7. Launch: run_stock_bot.bat

⚙ Privacy Mode Note Critical

⚠ By default, Telegram bots only see commands, not plain messages. This bot needs to READ the order/transfer/GRN templates posted by agents, so you MUST disable privacy:

BotFather → /mybots → [your bot] → Bot Settings → Group Privacy → Turn OFF

Without this, the listener will receive nothing from the topics.

🔄 Migration from Old Bot

If you were running the old upload-based stock_bot.py, stop it before launching the new stock_bot_listener.py. Both cannot run on the same bot token simultaneously.

Old files (stock_bot.py, process_stock.py) can stay in the folder as an AutoCount-reconciliation fallback. The new bot uses different files: orders_log.json, grn_log.json, transfers_log.json, unknown_skus.json.
